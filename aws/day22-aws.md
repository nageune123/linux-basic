# AWS Day 22 — ECS Auto Scaling

- 실습일: 2026-09-19
- 목표: CPU 부하에 따른 Fargate 태스크 자동 확장·축소 확인.

## 설정

- 서비스: `practice-ecs-service`
- 태스크 수: 최소 1개, 최대 2개.
- 대상 추적 정책: `practice-ecs-cpu50`, 평균 CPU 목표 50%.

## 검증 결과

- ApacheBench로 동시 요청 50개, 5분간 부하 테스트.
- 요청 469,965건, 실패 0건, 초당 약 1,567건 처리.
- 그래프에서 평균 CPU 약 82.83% 확인.
- CloudWatch 확장 경보 발생 후 태스크 1개 → 2개 자동 확장.
- 실제 태스크 2개 실행 중 확인.
- 자동 축소 2개 → 1개: 아직 확인 전.

## 배운 점

- 최대 CPU와 평균 CPU를 구분하고 경보 조건을 함께 확인한다.
- 스케일링 활동 기록과 실제 실행 중인 태스크 수로 동작을 검증한다.
